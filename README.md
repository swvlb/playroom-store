# Playroom

Небольшой каталог видеоигр на React. Данные об играх загружаются через RAWG API, а выбранные игры можно сохранять в локальную коллекцию.

Готовая версия: https://swvlb.github.io/playroom-store/

## Возможности

- просмотр списка игр;
- поиск по названию;
- добавление игр в коллекцию;
- сохранение коллекции в браузере.

## Запуск проекта

```bash
npm install
cp .env.example .env.local
npm run dev
```

В файле `.env.local` нужно указать ключ RAWG API. После запуска адрес сайта появится в терминале.

## Технологии

React, Vite, Axios и RAWG API.
